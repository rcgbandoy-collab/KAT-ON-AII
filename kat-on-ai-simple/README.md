# KAT-ON-AI

An AI-powered educational reviewer and gamified learning platform.

## Features

- AI-powered educational assistance
- Interactive quizzes
- Battle game
- Matching game
- Memory game
- Quiz game
- Typing race
- Word search
- Other interactive learning activities

## Technologies

- PHP
- HTML
- CSS
- JavaScript
- Groq AI API
- MySQL (local development environment)

## Installation

1. Install Laragon.
2. Clone or download this repository.
3. Place the project inside Laragon's www folder.
4. Configure your private config.php.
5. Start Apache and MySQL.
6. Open the project through your local server.

## Security

Never upload API keys, passwords, or private credentials.

See config.example.php for the configuration template.
